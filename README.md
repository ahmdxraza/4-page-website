# 4 Page Website

A simple **4-Page Website** created as an HTML and CSS assignment.
This project focuses on creating multiple linked web pages with a consistent layout and navigation.

## 🔗 Live Demo

[View 4 Page Website](https://ahmdxraza.github.io/4-page-website/)

## 🛠️ Technologies Used

* HTML
* CSS

## ✨ Features

* 4 linked web pages
* Navigation menu
* Headings and paragraphs
* Images
* Links
* Lists
* Simple and clean design
* Basic CSS styling

